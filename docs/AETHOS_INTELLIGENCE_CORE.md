# Aethos Intelligence Core

## Implemented

- Astro-Integration Kernel types and utilities for zodiac conversion, aspects, retrograde/station detection, natal chart scaffolding, transit events, and timing windows.
- Demo ephemeris provider with deterministic stable sample values.
- Timing intelligence layer with theme scoring, intensity, confidence, summaries, reflections, and action experiments.
- EMA-style journal calibration types and baseline comparison functions.
- Narrative scratchpad/orchestrator scaffold with deterministic agent notes and report drafts.
- UI upgrades for dashboard, profile, timing lab, and reports.

## Deterministic now

The current implementation is deterministic demo mode. The same demo inputs produce stable sample outputs. It does not claim Swiss Ephemeris-grade calculation.

## Requires future backend

Production planetary positions, houses, retrogrades, stations, and exact hits should be computed by a server-side Swiss Ephemeris service or equivalent deterministic ephemeris provider.
