# Narrative Service

The narrative service is a deterministic scaffold for future multi-agent synthesis. It does not call external LLM APIs.

Scratchpad sections include input context, chart facts, timing events, journal signals, theme scores, interpretive constraints, planning notes, report draft, and responsible-use notes.

Planning and writing agents currently produce deterministic template notes. The structure is ready for future server-side LLM agents, but the MVP does not depend on them.
