# Timing Intelligence

Aethos converts structured transit events into timing windows with start, peak, end, source events, intensity, confidence, theme scores, summaries, reflections, action experiments, and responsible-use notes.

The system uses rule-based mappings. For example, Mars hard aspects can raise Agency, Conflict, and Decision Pressure; Saturn hard aspects can raise Structure and Responsibility; Mercury station/retrograde conditions can raise Communication and Revision.

Timing windows are context markers for observation and planning. They are not commands or predictions.
