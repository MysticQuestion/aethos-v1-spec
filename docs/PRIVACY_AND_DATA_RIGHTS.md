# Privacy and Data Rights

Aethos is designed to support export and deletion workflows. This is not a claim of GDPR, CCPA, HIPAA, or other legal compliance.

## Sensitive data

- Birth date, time, location, timezone, and coordinates.
- Journal entries and EMA scores.
- Timing windows and reports.
- Action experiments and calibration signals.

## Local mode

Data is stored in this browser. Users can export local JSON, clear profile/birth data, or delete all local Aethos data.

## Supabase mode

Production Supabase mode requires authentication and Row Level Security policies so users can only read/write their own rows.
